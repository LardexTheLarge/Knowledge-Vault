# Stray ideas

- A "leave it local" badge that the user can put on a whole folder, not just a note.
- Weekly digest that runs entirely on-device and never leaves the machine.
- Import from a plain folder should preserve the folder tree. Flat imports lose the
  meaning of the structure.
- What if the approval panel showed the exact character count per note, not just
  in total? People liked the specificity in the interviews.
- Bad idea: a "share to community" button. Delete on sight.
- Maybe a small printable card in the box for the physical edition. Nothing to do
  with software, but it would be nice.
- Look up whether the Prompt API can run while the laptop is on battery saver;
  the demo machine throttled during the first recording.
