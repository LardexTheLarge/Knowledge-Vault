# Attention and tools — reading notes

Notes from three essays I read in one sitting. The common thread: tools that
remove friction also remove the small pauses where thinking happens.

## On capture

The argument that a note app should make capture effortless is only half true.
Effortless capture produces a landfill. The useful property is not speed of
capture but quality of resurfacing: will I meet this note again when it matters?

Implication for Atlas: search that actually finds things is worth more than a
faster new-note button.

## On the default

Defaults are the real product decisions. If the default is "send everything to the
cloud", the privacy setting is decoration. If the default is "nothing leaves until
you say so", the product has a point of view.

Implication: private is the default for every imported note. Sharing is an
explicit, per-note choice with a visible marker.

## On friction that earns its place

Some friction is good: a confirmation before publishing, a preview before sending,
a label on an AI answer that says where it ran. The test is whether the pause
changes a decision. If it does not, remove it.

Implication: one approval panel per cloud request. Not a settings toggle buried
three levels deep, and not a modal on every keystroke.

## Quotes

> "A tool that hides where the work happens is asking for credit it has not earned."

> "The pause is where the judgement lives."
